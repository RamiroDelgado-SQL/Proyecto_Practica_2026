Comercios de Villa Tech

Definición del problema

En la ciudad ficticia de Villa Tech, los pequeños comercios tienen dificultades para gestionar sus ventas, controlar el stock y llevar un registro ordenado de sus productos. Actualmente, muchos realizan estas tareas de forma manual, lo que genera errores, pérdida de información y baja eficiencia en la atención al cliente.

------Objetivo General

Desarrollar un sistema digital que permita a los comercios de Villa Tech gestionar de manera eficiente sus ventas, productos y stock, optimizando los procesos diarios y reduciendo errores.

-----Objetivos Específicos
Implementar un módulo para registrar y controlar el stock de productos.
Desarrollar una funcionalidad para registrar ventas de forma rápida y sencilla.
Generar reportes básicos que permitan analizar las ventas y el rendimiento del negocio.

------Beneficiarios
Los principales beneficiarios serán los dueños y empleados de los comercios de Villa Tech, quienes podrán mejorar la organización de su negocio. De manera indirecta, también se beneficiarán los clientes, ya que recibirán una atención más rápida y eficiente.

-------Alcance del proyecto
El sistema permitirá registrar productos, controlar el stock y gestionar ventas dentro de un comercio. No incluirá funcionalidades avanzadas como facturación electrónica ni integración con sistemas externos. El proyecto estará enfocado en brindar una solución simple, funcional y fácil de usar
